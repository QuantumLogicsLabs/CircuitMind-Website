# CircuitMind Docs Site

React + react-router-dom documentation website for the CircuitMind pipeline.

## Pages

| Route | Description |
|---|---|
| `/` | Overview & module cards |
| `/pipeline` | Full data-flow walkthrough |
| `/generate` | Generate module docs |
| `/explain` | Explain module docs |
| `/diagnose` | Diagnose module docs |
| `/export` | Export module docs |
| `/api` | FastAPI endpoint reference |

## Run

```bash
npm install
npm start
```

Open http://localhost:3000
